# MoodyEats – Online Food Ordering System

MoodyEats is an online food ordering website that allows users to explore food items and order their favorite meals online. The project aims to provide a convenient and user-friendly food ordering experience through a simple and attractive interface.

## Features

- Browse food items and explore the menu.
- User registration and login.
- Add food items to the cart.
- Manage cart items and quantities.
- Place food orders online.
- Admin panel for managing food items and orders.

*Note: Keep only the features that are actually implemented in your project.*

## Tech Stack

- **Frontend:** React.js, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Git, GitHub, VS Code

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Mintukumari-0019/moodyEats.git
cd moodyEats
```

### 2. Install frontend dependencies

```bash
cd frontend
npm install
npm run dev
```

### 3. Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
```

Configure your backend environment variables in a `.env` file, including the required database connection details.

Start the backend using the appropriate script defined in `backend/package.json`.
